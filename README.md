# ✦ Mahdieh Karizi — Interactive Developer Portfolio

> A small journey through space, code, and imagination.

An interactive personal portfolio designed to present my background, projects, technical skills, and interests through a more playful experience than a traditional developer portfolio.

Instead of a conventional collection of cards and sections, the website turns the portfolio into a small interactive world: a cosmic landing page leads into a scroll-driven forest where projects appear as tiny mushroom houses along the path.

## ✨ About the Project

This portfolio was created to combine two things I enjoy:

**Engineering** — building functional, responsive, maintainable web experiences.

**Creative interaction** — using animation, illustration, and storytelling to make an interface feel memorable.

The result is a portfolio that behaves more like a small interactive scene than a traditional personal website.

The experience begins in space, where a small UFO approaches the landing area. As the visitor continues scrolling, the scene transforms into an illustrated forest containing selected projects, followed by information about my background, skills, and ways to get in touch.

## 🎨 Design Direction

The visual identity of the portfolio is inspired by a combination of:

**Space**  
A symbol of curiosity, exploration, and constantly learning something new.

**Fantasy**  
A small illustrated character, UFO, glowing elements, mushrooms, fireflies, and a magical forest create a world around the portfolio.

**Interaction**  
Projects are not simply displayed in a grid. They become part of the visitor's journey.

**Engineering**  
The experience is built from code, with custom SVG artwork, CSS animation, DOM manipulation, and scroll-based interactions.
